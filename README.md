# 数覚バトル ナンバーコア！

数字を組み合わせて「コアナンバー」を狙え！
計算した数字によって攻撃・防御などのコマンドが変わり、コアナンバーぴったりの **JUST** を出すとCORE POWERが発動する、数の感覚を楽しみながら育てるバトルゲームです。

## 🎮 ゲーム概要

プレイヤーはモンスターCPUと1対1でバトルします。

手札に配られた数字カードから最大3枚を選び、四則演算で数字を作ります。作った数字がコアナンバーにどれだけ近いかによって、発動するコマンドが決まります。

現在はゲームシステムを中心としたプロトタイプで、キャラクターは絵文字を使用しています。将来的にはナビキャラやオリジナルモンスターに置き換えられます。

## 🔢 基本ルール

- コアナンバー：**20 / 30 / 50 / 100** から選択
- 手札：5枚
- 1ターンに使用できるカード：最大3枚
- 数字カード：1〜20
- 0のカードは使用しない
- 四則演算：＋・−・×・÷
- プレイヤーHP：10
- CPU HP：10
- プレイヤーの思考時間：20秒
- 時間切れ：ターン終了してCPUへ

## 👾 モンスター

コアナンバーごとにモンスターと性格が変わります。

| モンスター | コア | 性格 | 固有能力 | 使用演算 |
|---|---:|---|---|---|
| ぷるんスライム | 20 | かんたん | ぷるぷるガード | ＋・− |
| ゴブリン | 30 | ふつう | JUSTハンター | 四則演算 |
| ドラゴン | 50 | てんさい | ドラゴンブレス | 四則演算 |
| 星喰いの幻獣 | 100 | てんさい | コアイーター | 四則演算 |

モンスターによって使える演算やCPUの思考傾向が変わるため、同じ計算だけを繰り返すゲームにならないようにしています。

## ⚔️ コマンド

コアナンバーを中心に、近い数字ほど強いコマンドになります。

| 作った数字 | コマンド | 基本効果 |
|---|---|---|
| コア−10〜コア−7 | 🛡️ 防御 | 次の攻撃を軽減 |
| コア−6〜コア−4 | ⚔️ 攻撃 | 1ダメージ |
| コア−3〜コア−1 | 💥 強攻撃 | 2ダメージ |
| **コア** | 🌟 JUST | 次の攻撃×3のCORE POWER |
| コア＋1〜コア＋3 | 💥 強攻撃 | 2ダメージ |
| コア＋4〜コア＋6 | ⚔️ 攻撃 | 1ダメージ |
| コア＋7〜コア＋10 | 💚 回復 | HPを3回復 |

範囲外の数字はOUTとなり、基本的にコマンドを発動できません。

## 🌟 JUST / CORE POWER

コアナンバーと同じ数字を作るとJUSTです。

例：

`12 ＋ 18 ＝ 30`

→ 🌟 JUST！

JUSTすると、次の攻撃が **3倍** になるCORE POWERがチャージされます。JUSTを単なる正解ではなく、「もう一度JUSTを狙いたい」と思えるゲーム上の目標にしています。

## 🧠 CPUの性格

CPUもプレイヤーと同じルールで数字を組み合わせます。

- かんたん：候補からランダムに選ぶ
- ふつう：コアに近い数字を優先
- てんさい：JUSTを優先し、状況に応じて強攻撃も狙う

CPUのターンでは、考えていること、計算式、作った数字、発動コマンドを表示します。相手の計算を見ること自体が「みんなの作り方」の学習になります。

## 🎯 ゲットチャンス

CPUモンスターを倒すと「ゲットチャンス」が始まります。

制限時間15秒以内にコアナンバーの **JUST** を作ることができれば、モンスターをGETできます。

成功：🎉 モンスターGET！

失敗：💨 モンスターが逃げる！

獲得したモンスターはブラウザのlocalStorageに保存されます。

## 📚 発見図鑑 / みんなの30

バトルで作った式は「発見図鑑」に自動登録されます。

例えば30なら、

`12＋18＝30`

`5×6＝30`

`40−10＝30`

のように、同じ数を作る複数の方法を集められます。

単なる計算問題ではなく、**「同じ数を何通りで作れるか」**を遊びにすることで、数の構成や関係に目を向けることを狙っています。

## 🌱 数覚を育てるゲームとして

このゲームでは、単純な計算だけではなく、次のような数の感覚を使います。

- 目標の数に近いか遠いか
- コアより大きいか小さいか
- あといくつでコアになるか
- 複数の数字をどう組み合わせるか
- どのカードを今使うか
- JUSTを狙うか、別のコマンドを選ぶか
- 同じ数を別の方法でも作れるか

「正解すること」だけではなく、**数字を見て、関係を考え、狙った数を作ること**を大切にしています。
