# 数覚バトル ナンバーコア！

数字を組み合わせて「CORE」をねらう、ファンタジー型の数覚バトルゲームです。

単純な計算練習ではなく、

**「目標まであといくつ？」→「どう組み合わせる？」→「どの作戦で戦う？」→「別の作り方もある？」**

をゲームの中で繰り返すことをねらっています。

## いま遊べるもの

- CORE：20 / 30 / 50 / 100
- 手札：5枚
- 1回に使えるカード：2〜3枚
- 数字カード：1〜20
- ＋・−・×・÷
- 1ターン20秒
- カードチェンジ：1ターン1回、残り時間3秒を使う
- 防御 / 攻撃 / 強攻撃 / JUST / 回復
- JUST COMBO
- JUST後のCORE POWER
- CPUの思考表示
- ファンタジー背景
- ナビキャラのATTACK / SPECIAL演出
- モンスターGET
- モンスター図鑑
- 発見図鑑
- ブラウザ保存

## COREをねらう

作った数字がCOREに近いほど強いコマンドになります。

| COREとの差 | コマンド |
|---:|---|
| −10〜−7 | 防御 |
| −6〜−4 | 攻撃 |
| −3〜−1 | 強攻撃 |
| 0 | JUST |
| ＋1〜＋3 | 強攻撃 |
| ＋4〜＋6 | 攻撃 |
| ＋7〜＋10 | 回復 |

範囲外はOUTです。

ゲーム画面では、現在作った数字とCOREの距離を大きく表示します。

## 3つの作戦

毎ターン、次の作戦を選べます。

### JUSTをねらう
COREと同じ数字を作ることを優先する考え方です。

### できるだけ近づく
JUSTに届かなくても、COREとの差を小さくすることを優先します。

### 安全に戦う
防御や通常攻撃を使いながら、無理をせず戦います。

作戦を先に決めることで、「計算できたから押す」だけでなく「何をねらっているか」を意識できるようにしています。

## JUSTとJUST COMBO

COREとまったく同じ数字を作るとJUSTです。

たとえばCOREが30なら、

`12 ＋ 18 = 30`

でJUST。

JUSTするとCORE POWERがチャージされ、次の攻撃が3倍になります。

さらにJUSTを連続して成功するとJUST COMBOが増えます。

つまり、

**近づく → JUST → CORE POWER → 強い攻撃 → もう一度JUST**

という流れを作れます。

## モンスター

COREごとに相手が1体に固定されるのではなく、複数のモンスターからランダムで登場します。

現在は `navi-character-` の実在するファンタジーモンスター素材を使い、通常敵26体＋レア敵4体の30体構成です。

| CORE | 登場例 | タイプ |
|---:|---|---|
| 20 | ぷるんスライム / どんぐりリーフ / ベリーリーフ / キャンディコーラル | 初級・防御・回復・いたずら |
| 30 | こもりんバット / きのこっこ / はっぱリス / コグホイールビートル / ホローハット | JUST・回復・防御・計算・変則 |
| 50 | もふウルフ / フロストファング / クラウドラビット / コバルトカマキリ / ミズタマカッパ / ハニードロップベア など | 攻撃・時間・回避・一撃・いたずら・回復 |
| 100 | アイアンリーフパンサー / エンバーウィング / ランタンアイモス / ムーンリットウィスプ / ナイトスノーパフ / クローバーマンドラゴラ など | 強敵・攻撃・JUST・変則・防御・回復 |

さらに低確率で、アクアスライムキング、クリムゾンインフェルノドラゴン、アビサルミラーレヴィアタン、アズールスカイドラゴンなどのレア敵が登場します。

モンスターには、ガード、回復、JUST狙い、反射、怒り、時間圧力、回避、変則型などの個性を持たせています。同じCOREでも相手によって、考えるポイントが変わります。

## CPUの考え方

CPUはプレイヤーと同じ数字カードのルールで式を作ります。

CPUのターンには、

- どんな式を選んだか
- COREとの差はいくつか
- JUSTを狙ったのか
- どのコマンドを使うのか

を表示します。

相手の計算を見ること自体が、数字の組み合わせ方を見る機会になります。

## モンスター図鑑

出会ったモンスターはブラウザに保存され、図鑑に登録されます。

図鑑はゲーム画面を圧迫しないよう、折りたたみ式にしています。タブレットでは広めに一覧表示し、スマートフォンでは列数を減らして見やすくします。

未発見のモンスターは「？？？？」として表示され、レアモンスターは特別表示されます。

## 発見図鑑

バトルで作った式は自動的に図鑑へ保存されます。

たとえばCORE 30なら、

`12 ＋ 18 = 30`

`5 × 6 = 30`

`40 − 10 = 30`

など、異なる作り方を集められます。

同じCOREでも「別の作り方がある」と気づくことが、このゲームの重要な目的です。

画面の「みんなの30」などには、実際に見つかった式が表示されます。

## ゲットチャンス

モンスターを倒すと、15秒間のGET CHANCEが始まります。

もう一度COREをJUSTで作ることができれば、そのモンスターを仲間にできます。

モンスターの発見状況はブラウザに保存されます。

## ナビキャラ

プレイヤー側には `TT-sensei/navi-character-` のファンタジーキャラクターを使用しています。

- かい・魔導士
- そら・剣士
- りく・忍者
- つき・アーチャー
- なみ・守護騎士
- さく・僧侶

通常時はSTAND、攻撃時はキャラクター別ATTACK、JUST時はSPECIAL画像を表示します。

## ファンタジー演出

バトルごとに背景が変わります。

現在は、

- 森
- 洞窟
- 遺跡

を使用しています。

モンスターは実際のファンタジーモンスター画像を表示し、旧来の敵絵文字には依存しません。

## 数覚を育てるポイント

このゲームで大切にしているのは、計算の速さだけではありません。

- COREより大きいか小さいか
- COREまであといくつか
- どのカードを組み合わせるか
- 2枚と3枚のどちらがよいか
- ＋・−・×・÷のどれを使うか
- JUSTを狙うか、近い数字で安全に戦うか
- 同じ数を別の方法で作れるか
- 相手はどんな作り方をしたか

という「数の関係」をゲームの中心にしています。

## データ保存

ブラウザの `localStorage` を利用します。

主な保存データは次の通りです。

- `numberCoreDiscovery`：発見した計算式
- `numberCoreMonsters`：出会ったモンスター
- `numberCoreStats`：バトル数・勝敗・JUST回数

アカウント登録やサーバーを必要としない、ブラウザ完結型です。

## 対応環境

HTML / CSS / JavaScriptのみで動作します。

GitHub Pagesで公開できます。

スマートフォンにも対応していますが、**学校のタブレットでの操作性を優先**しています。
