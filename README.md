# 数覚バトル ナンバーコア！

数字を組み合わせて「コアナンバー」を狙え！
計算した数字によって攻撃・防御などのコマンドが変わり、30ぴったりの **JUST** を出すと追加効果が発生する、数の感覚を楽しみながら育てるバトルゲームです。

## 🎮 ゲーム概要

プレイヤーはモンスターCPUと1対1でバトルします。

手札に配られた数字カードから最大3枚を選び、四則演算で数字を作ります。作った数字がコアナンバーにどれだけ近いかによって、発動するコマンドが決まります。

現在の試作版では、キャラクターとモンスターは絵文字を使用しています。将来的にはナビキャラやオリジナルモンスターに置き換える予定です。

## 🔢 基本ルール

- コアナンバー：**30**
- 手札：**5枚**
- 1ターンに使用できるカード：**最大3枚**
- 数字カード：**1〜20**
- 0のカードは使用しない
- 四則演算：＋・−・×・÷
- プレイヤーHP：10
- CPU HP：10
- プレイヤーの思考時間：20秒
- 時間切れ：ターン終了してCPUへ

## ⚔️ コマンド

コアナンバー30を中心に、近い数字ほど強いコマンドになります。

| 作った数字 | コマンド | 基本効果 |
|---|---|---|
| 20〜23 | 🛡️ 防御 | 次の攻撃を軽減 |
| 24〜26 | ⚔️ 攻撃 | 1ダメージ |
| **30** | 🌟 JUST | 通常効果＋追加効果 |
| 27〜29 / 31〜33 | 💥 強攻撃 | 2ダメージ |
| 34〜36 | ⚔️ 攻撃 | 1ダメージ |
| 37〜40 | 🛡️ 防御 | 次の攻撃を軽減 |

範囲外の数字は **OUT** となり、基本的に何も起こりません。

「コアナンバーに近いほど有利」という仕組みにより、単に大きな数字を作るのではなく、狙った数字を作ることをゲームの中心にしています。

## 🌟 JUST

コアナンバーと同じ **30** を作るとJUSTです。

例：

`12 ＋ 18 ＝ 30`

→ 🌟 JUST！

JUSTでは、そのコマンドの通常効果に追加効果が加わります。

## 👾 CPUバトル

CPUもプレイヤーと同じルールで数字を組み合わせます。

CPUのターンでは、

1. CPUが数字を考える
2. 計算式を表示
3. 作った数字を表示
4. 発動するコマンドを表示
5. 行動を実行

という流れで、相手が何をしているのか分かるようにしています。

## 🎯 ゲットチャンス

CPUモンスターを倒すと「ゲットチャンス」が始まります。

制限時間内に **30 JUST** を作ることができれば、モンスターをGETできます。

成功：🎉 モンスターGET！

失敗：💨 モンスターが逃げる！

## 🧠 数覚を育てるゲームとして

このゲームでは、単純な計算だけではなく、次のような数の感覚を使います。

- 目標の数に近いか遠いか
- 30より大きいか小さいか
- あといくつで30になるか
- 複数の数字をどう組み合わせるか
- どのカードを今使うか
- JUSTを狙うか、別のコマンドを選ぶか

「正解すること」だけではなく、**数字を見て、関係を考え、狙った数を作ること**を大切にしています。
