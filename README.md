# 数覚バトル ナンバーコア！

数字を組み合わせて「コアナンバー」を狙え！

**近づける・ぴったり合わせる・別の作り方を発見する。**
計算した数字によってバトルコマンドが変化し、コアナンバーぴったりの **JUST** を出すとCORE POWERが発動します。

算数の計算練習をそのままゲームにするのではなく、遊びながら「数をどう組み合わせるか」「あといくつか」「どちらが近いか」を考えることを目指したゲームです。

## ゲーム概要

プレイヤーはファンタジー世界のモンスターCPUと1対1でバトルします。

手札の数字カードから2〜3枚を選び、＋・−・×・÷を使って数字を作ります。作った数字がコアナンバーに近いほど強いコマンドが発動します。

コアナンバーは **20 / 30 / 50 / 100** から選択できます。コアによって相手モンスターも変わります。

画面はタブレットで遊びやすいことを重視し、数字カードや計算操作を大きめにしています。

## 基本ルール

- コアナンバー：20 / 30 / 50 / 100
- 手札：5枚
- 1ターンに使えるカード：最大3枚
- 数字カード：1〜20
- 四則演算：＋・−・×・÷
- プレイヤーHP：10
- モンスターHP：10
- 通常ターン：20秒
- 時間切れ：ターン終了してCPUへ
- 計算は左から順番に処理
- 3枚使用時は同じ演算子を連続して使用しない

## モンスター

コアナンバーごとに相手が変わり、性格や使える演算も異なります。

| モンスター | コア | 性格 | 固有能力 | 使用演算 |
|---|---:|---|---|---|
| ぷるんスライム | 20 | かんたん | ぷるぷるガード | ＋・− |
| こもりんバット | 30 | ふつう | JUSTハンター | 四則演算 |
| もふウルフ | 50 | てんさい | ドラゴンブレス | 四則演算 |
| プリズムテールドレイク | 100 | てんさい | コアイーター | 四則演算 |

モンスターには `navi-character-` のファンタジー用オリジナルモンスター素材を使用しています。ゲーム内では絵文字ではなく、実際のモンスター画像を表示します。

## ナビキャラ

プレイヤー側には `navi-character-` のファンタジーキャラクターを使用します。

| キャラクター | ジョブ |
|---|---|
| かい | 魔導士 |
| そら | 剣士 |
| りく | 忍者 |
| つき | アーチャー |
| なみ | 守護騎士 |
| さく | 僧侶 |

バトル開始時にキャラクターが選ばれ、通常時はSTAND画像を表示します。

攻撃時にはキャラクターごとの **ATTACK**、JUST時には専用の **SPECIAL** 素材へ切り替わる演出を入れています。

## コマンド

作った数字がコアナンバーにどれだけ近いかでコマンドが決まります。

| 作った数字 | コマンド | 基本効果 |
|---|---|---|
| コア−10〜コア−7 | 防御 | 次の攻撃を軽減 |
| コア−6〜コア−4 | 攻撃 | 1ダメージ |
| コア−3〜コア−1 | 強攻撃 | 2ダメージ |
| **コアと同じ** | **JUST** | 次の攻撃×3のCORE POWER |
| コア＋1〜コア＋3 | 強攻撃 | 2ダメージ |
| コア＋4〜コア＋6 | 攻撃 | 1ダメージ |
| コア＋7〜コア＋10 | 回復 | HPを3回復 |

範囲外の数字はOUTとなり、コマンドを発動できません。

## JUST / CORE POWER

コアナンバーと同じ数字を作ると **JUST**。

たとえばコア30なら、

`12 ＋ 18 ＝ 30`

でJUSTです。

JUSTするとCORE POWERがチャージされ、次の攻撃ダメージが3倍になります。

つまり「とにかく攻撃する」のではなく、

**近い数字を狙う → JUSTを狙う → 強力な攻撃につなげる**

という判断がゲームのポイントになります。

## CPUの思考

CPUもプレイヤーと同じルールでカードを組み合わせます。

- かんたん：候補からランダムに選択
- ふつう：コアに近い数字を優先
- てんさい：JUSTを優先
- 敵HPが少ないとき：強攻撃を狙う
- プレイヤーHPが少ないとき：JUSTを狙う

CPUのターンでは、考えていること、計算式、作った数字、発動コマンドを表示します。

「相手がどんな作り方をしたか」を見ることも、数の構成を学ぶ機会になります。

## ゲットチャンス

モンスターを倒すと、15秒間の「ゲットチャンス」が始まります。

ここでもう一度コアナンバーのJUSTを作ることができれば、倒したモンスターを仲間にできます。

成功するとモンスター図鑑に登録されます。

獲得状況はブラウザの `localStorage` に保存されるため、同じ端末・ブラウザなら次回もコレクションを残せます。

## 発見図鑑

バトル中に作った計算式は自動的に「発見図鑑」に記録されます。

たとえば30なら、

`12 ＋ 18 ＝ 30`

`5 × 6 ＝ 30`

`40 − 10 ＝ 30`

のように、同じ数を作る複数の方法を集められます。

「答えが30になる計算」を覚えるだけではなく、**30をどう作れるか**を考えることが目的です。

## 数覚を育てるポイント

このゲームでは、次のような数の感覚を自然に使います。

- 目標の数に近いか
- 目標より大きいか小さいか
- あといくつで目標になるか
- 2枚と3枚のカードをどう組み合わせるか
- ＋・−・×・÷のどれを使うか
- JUSTを狙うか、安全に攻撃するか
- 同じ数を別の方法でも作れるか
- 相手の作り方を見て考える

「正解したか」だけではなく、**数字の関係を見て、狙った数を作ること**を大切にしています。

## ビジュアル・演出

ファンタジーバトルとしての楽しさも重視しています。

- ファンタジー背景をランダム表示
- ナビキャラのSTAND画像
- キャラクター別ATTACK演出
- キャラクター別SPECIAL演出
- JUST時の強調演出
- ダメージ演出
- モンスター画像によるバトル表示
- モンスターGETにつながるコレクション要素

森・洞窟・遺跡などの背景を使い、毎回少し違った冒険感を出します。

## データ保存

ブラウザの `localStorage` を利用しています。

保存する主なデータは次の2つです。

- `numberCoreDiscovery`：発見した計算方法
- `numberCoreMonsters`：GETしたモンスター

サーバーやアカウント登録を必要としない、ブラウザ完結型の学習ゲームです。

## 対応環境

HTML / CSS / JavaScriptだけで動作します。

GitHub Pagesで公開でき、学校のタブレットからブラウザで利用できます。
